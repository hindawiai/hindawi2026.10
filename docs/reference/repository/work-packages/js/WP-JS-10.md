# WP-JS-10: Arduino from the browser

Replaces or complements: ide/arduino.

Transduce in the page and flash through Web Serial, so students need no local toolchain for their boards.

Done when: The Arduino sample compiles from a native sketch and runs on an ESP32 and an Uno.

Write it in plain JavaScript (ES modules), with no build step beyond what the static site needs, and keep the Python tool as the reference until the parity check passes.
