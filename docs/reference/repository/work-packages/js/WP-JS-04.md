# WP-JS-04: Romenagri in the browser

Replaces or complements: Chintamani Romenagri (uni2acii, acii2cf, acii2uni, fixuninum).

Compile the C sources to WebAssembly with Emscripten, or port them; expose one function per tool.

Done when: Identical C-level forms to the native tools for every name in samples/gate in every language.

Write it in plain JavaScript (ES modules), with no build step beyond what the static site needs, and keep the Python tool as the reference until the parity check passes.
